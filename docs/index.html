Questions

Is it really free?

Yes. NotchPilot is free and open source under the MIT license, with no trial, no ads and no paid tier. Contributions are welcome on GitHub.

macOS says it can't verify the app

The app isn't notarized by Apple yet. Follow the 2-step install guide; you only do it once, and updates install without it.

Does it work on Macs without a notch?

Yes. On Macs without a notch, or on external displays, the island appears as a small pill at the top of the screen.

Does it send my code or prompts anywhere?

No. Agent status comes from small local hooks, and usage is read from log files already on your Mac. The only network requests are weather (MET Norway) and update checks (GitHub).

How do updates work?

The app checks once a day and installs updates in one click. Every release is signed, so only genuine updates are accepted.
