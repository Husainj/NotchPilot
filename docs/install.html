Installing NotchPilot

NotchPilot is downloaded from GitHub and isn't notarized by Apple yet, so the first time you open it macOS asks you to confirm. You only do this once; updates install without it.

With Homebrew: brew install --cask husainj/tap/notchpilot, then do step 2.

1. Install

  1. Download the latest .dmg from GitHub Releases and open it.
  2. Drag NotchPilot onto the Applications folder.

2. Open it the first time

  1. Double-click NotchPilot in Applications. macOS shows "Apple could not verify NotchPilot…" — click Done.
  2. Open System Settings → Privacy & Security and scroll down.
  3. Next to "NotchPilot was blocked to protect your Mac", click Open Anyway and confirm with your password or Touch ID.

Prefer Terminal? xattr -dr com.apple.quarantine /Applications/NotchPilot.app then open NotchPilot.

3. Use it

The island appears over your notch. Hover it to expand. Settings live in the menu bar icon.

Optional permissions

  • Accessibility — only for the custom volume/brightness HUD (Settings → System). After updating NotchPilot you may need to toggle it off and on again in System Settings → Privacy & Security → Accessibility.
  • Automation — lets NotchPilot read the current song from Music and Spotify.
  • Calendars & Reminders — shows your upcoming events and Join buttons for calls.
  • Location — only for local weather; you can type a city instead.
  • Camera — only for the optional Mirror tab.
