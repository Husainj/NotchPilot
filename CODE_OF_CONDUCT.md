# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or any project space.

To report unacceptable behaviour, message the maintainer privately on X ([@husain_j53](https://x.com/husain_j53)) or open a private GitHub security advisory. Reports are handled confidentially. Maintainers may remove comments, issues or contributors that break these rules.
